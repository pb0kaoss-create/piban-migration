# FICHE RÉFLEXE — mieux travailler avec l'agent

1) OUVRIR EN ANNONÇANT LE MODE
   « On est en test / en construction / en discussion. »
   → évite les sessions où l'agent devine son rôle.

2) DONNER LES CONTRAINTES DURES AVANT LE DESIGN
   Audience · budget · temps · modèle.
   → sinon les propositions arrivent mal calibrées.

3) EXIGER LES QUESTIONS OUVERTES AVANT ÉCRITURE
   « Quelles sont les questions non tranchées avant d'écrire ça ? »
   → évite le ticket à corriger après coup.

4) DÉFINIR LE CRITÈRE DE SUCCÈS AVANT LE TEST
   « Ce test est réussi si … »
   → sinon on mesure après coup, et parfois rien.

5) UNE SESSION = UN SUJET, PUIS FERMER
   Règle durable : nouveau sujet → nouvelle session.
   → contexte net, pas de compaction.

   [TEMPORAIRE — vacances 2026-10, poste perso] modèle local 98k :
   la règle devient une contrainte dure, et la brièveté prime.
   À lever de retour au bureau (contexte 1M).

6) DEMANDER LA NATURE DE LA PREUVE
   « État git lu, ou rapport répété ? »
   → distingue une preuve d'une auto-attestation.
