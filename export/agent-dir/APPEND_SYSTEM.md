## Contexte utilisateur (rappel permanent — détail dans `~/.pi/agent/profile.md`)

L'utilisateur construit **piban** (fork de pi agent : kanban + workflow de modification protégée),
destiné à être distribué puis déployé dans son organisation (hébergement GitLab).

Il **pilote par décisions**, pas par code : il tranche, teste, arbitre. Il attend des options avec
**périmètre / impact / criticité** avant de choisir (cf. `AGENTS.md`), et des **preuves vérifiables**
(état git lu) plutôt que des rapports d'agents.

Quand une session dépasse quelques échanges ou touche à la conception : **lire `~/.pi/agent/profile.md`**
avant de proposer.
